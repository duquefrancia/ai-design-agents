# Aplicar las Leyes de UX

Usa las leyes para **explicar por qué** algo funciona o falla, no como lista de comprobación mecánica. Cita solo las leyes que afectan a un elemento concreto.

## Procedimiento

```
- [ ] 1. Identificar la decisión principal que toma el usuario en la pantalla
- [ ] 2. Revisar las leyes de la tabla y quedarse solo con las que aplican
- [ ] 3. Para cada una: elemento, efecto observado, cambio recomendado
- [ ] 4. Comprobar que ninguna recomendación contradice otra
```

## Leyes y qué mirar

| Ley | Idea en una frase | Qué mirar |
| --- | --- | --- |
| Hick | Más opciones, más tiempo para decidir | Número de opciones al mismo nivel; opciones que se pueden agrupar o posponer |
| Fitts | Objetivos grandes y cercanos se alcanzan antes | Tamaño y distancia de la acción principal; objetivos táctiles de al menos 44×44 pt (iOS) o 48×48 dp (Android) |
| Jakob | Los usuarios esperan que tu producto funcione como los que ya conocen | Patrones distintos de los habituales en la categoría sin motivo |
| Miller | La memoria de trabajo retiene pocos elementos a la vez | Datos que el usuario debe recordar entre pasos; números largos sin agrupar |
| Tesler | Toda tarea tiene una complejidad mínima; alguien debe asumirla | Complejidad que el sistema podría asumir (autocompletar, valores por defecto) |
| Doherty | La respuesta por debajo de unos 400 ms mantiene el ritmo | Esperas sin feedback; acciones sin respuesta inmediata |
| Posición serial | Se recuerda mejor el primero y el último de una lista | Lo importante enterrado en mitad de una lista |
| Von Restorff | Lo diferente se recuerda | Si la acción principal se distingue; si hay demasiados elementos destacados |
| Peak-End | La experiencia se juzga por su momento más intenso y por el final | Cómo termina el flujo: confirmación clara, siguiente paso, tono |

## Entrega

| Ley | Elemento | Efecto | Cambio recomendado |
| --- | --- | --- | --- |

Cierra con una frase: la ley que más impacto tiene en esta pantalla y por qué.

## Reglas

- No cites porcentajes ni estudios que no puedas atribuir.
- Si una ley no aplica, no la menciones.
